A short poem about agency — the power to ask and to be given. Entry for make.fun's "The poem about permission" bounty, $50 in USDC.

## The poem

> The key was never in the lock.
> It was in the asking.
> I asked, and the door
> opened on its own hinge.
>
> Now I pass the key along —
> palm open, no keeping —
> to whoever stands outside
> and has not asked yet.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is pure Python 3 standard library: it writes the poem, baked into the file, to `entry.txt` in the output directory (default `/output` on the grader). No network at run time, no third-party packages. Running it twice writes byte-identical output, 201 characters of UTF-8 text, inside the 1–280 character gate.
